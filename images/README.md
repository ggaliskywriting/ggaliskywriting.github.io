Put your photos in this folder, then reference them from
`assets/js/entries.js` like so:

    photos: [
      { src: 'images/ridge.jpg', alt: 'A granite ridge under cloud' },
    ]

Resize to about 2500px on the long edge and save as JPEG at ~80% quality
before committing them. Full-resolution camera files make the repo huge and
the page slow.
